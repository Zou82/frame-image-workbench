# FRAME 1.0.0

首个公开版本，包含电脑本地网页版和独立 Android 应用。

## 下载

- `FRAME-1.0.0.apk`：Android 安装包，安装后直接配置自己的 API。
- `FRAME-Web-1.0.0.zip`：电脑本地网页版，解压后双击 `start.cmd`。
  需要 Node.js 22.12+，首次运行联网安装依赖。
- `SHA256SUMS.txt`：发布文件校验值。
- GitHub 自动提供的 Source code：包含网页、服务端、Android、测试和构建脚本的完整源码。

## 主要功能

- 自定义多个 API 地址、密钥与真实模型列表。
- 每项任务独立提示词、模型、参考图、比例、分辨率、画质和高级参数。
- JSON 一次导入多任务，统一默认值与单项覆盖。
- 500 草稿、100 并发、分页、筛选、跨页选择和选择性批改。
- 生成、参考图编辑、预览、历史、保存及图片复用。
- Android 原生网络、加密密钥、后台任务通知、系统文件选择器和相册保存。
- 中断任务不会自动重新提交。

## 验证与兼容性

36 项 JavaScript 测试、20 项针对正式签名 APK 的 Android 仪器测试通过。
Android 14 模拟器实测 100 任务后台并发完成、101 张输出，
以及多图编辑、JSON 导入导出、取消、失败隔离、重启中断和多种屏幕布局。
测试使用本地模拟接口，不产生付费生图调用。

Android 最低 8.0，要求 WebView/Chrome 105+；
实际测试为 Android 14 x86_64，旧 Android、ARM 与厂商系统尚未实机验证。
100 并发的使用效果取决于服务商限流和网络条件。

发布包不含个人 API 密钥、个人图片、历史数据或签名私钥。
